# P2.7 — VK-бот как дополнительный канал

**Статус:** PLANNED — собственный VK-канал, сначала режим Hermes и техническое
исследование, затем интеграция с ACP Gateway; проект и реализация ещё не созданы.
**Репозиторий:** будущий собственный VK-проект + `acp-gateway` (интеграция).
**Актуальное решение 2026-11-05:** [концепция и точка возврата](../plans/p2.7-vk-channel-concept.ru.md).
Ниже — исторические решения 2026-10-21/22; их минимальный scope и привязка порядка
заменены новым решением, но прежние требования owner identity и безопасности сохраняются.

Владелец выбрал VK по собственным предпочтениям доступности/удобства для СНГ.
Это продуктовый выбор, не исследование рынка или доказанная доступность для всех.
Решение 2026-10-21: VK идёт после [P4.13](connector-harness-adapters.ru.md) —
Codex/Claude Code CLI/Desktop и подключения существующего чата по ID из Telegram.
На дату решения прежняя неопределённость очереди была заменена; порядок Goose/multi-user отдельно не выбран. Новый порядок VK — в решении 2026-11-05.

## Исторические границы будущего adapter (2026-10-21/22)

Adapter общего application layer: компьютеры/агенты, managed dialogues, jobs/results,
human approvals, pairing и remote updates. Не создавать VK-специфичное владение или
второй updater. External identity привязывается к owner только проверенным способом,
не по совпавшему имени. Общий сервис для разных пользователей требует P4.10.

Перед реализацией проверить актуальные официальные контракты регистрации бота,
auth/events/callbacks, ограничения и эксплуатацию; выбрать SDK. Минимальный первый
scope выбран 2026-10-22 (см. ниже). Здесь не обещаются непроверенные тарифы, permissions или transport.
Добавление направления не разрешает автоматически начинать реализацию.


## Решение владельца 2026-10-21

VK подтверждён как следующий канал после поддержки Codex/Claude Code CLI/Desktop
и подключения чата агента по ID в Telegram. Scope общего application layer
сохраняется. Adapter пока не реализован; до кода нужны актуальные официальные
контракты и согласованный MVP. Этот приоритет не активирует multi-user автоматически.

## Первый рабочий scope — решение владельца 2026-10-22

VK и Telegram — равноправные входы одного диспетчера: общие чаты/jobs/approvals,
без ручного переключателя каналов. Первая полезная версия — выбор компьютера,
агента и чата, сообщения с текстом/кодом, результаты и подтверждения. Настройки,
remote updates и прочее администрирование можно добавлять позже; загрузка файлов
и изображений выделена в отдельный подэтап. Долгосрочный scope выше не отменён.
Общий core и проверенная owner identity обязательны; совпадение имени не является
привязкой пользователя. Статус OPEN и место после P4.13 сохранены.

Единый подтверждённый контракт multi-source чатов, permissions/подписок и
оставшиеся вопросы — [точка возврата P4.13, раздел 10](../plans/p4.13-resumption.ru.md#10-решения-продуктовой-прожарки-2026-10-22).
Это не реализация и не подтверждение возможностей VK API; auth/events/limits
и эксплуатационные ограничения необходимо проверить перед кодом.
