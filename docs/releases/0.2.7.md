# ACP Gateway 0.2.7

## Changed

- **Dialogues get a name.** Managed Codex and Claude Code never send a session
  title, so every dialogue appeared as «Без названия» in Telegram. The dispatcher
  now names an untitled dialogue after the first non-empty line of its first
  message (secrets masked, up to 60 characters). A title sent by the agent still
  replaces it. Existing untitled dialogues are named by their next message.

## Fixed

- Release CI no longer hangs or flakes in the connector maintenance tests. A test
  helper let a file error replace the cancellation of the activity watcher, so the
  test never finished; the ACL barrier test now retries the known pre-admission
  refusal. Connector runtime behaviour is unchanged.

## Upgrade

Dispatcher-only change: update the dispatcher. Connectors on 0.2.6 need no update.
